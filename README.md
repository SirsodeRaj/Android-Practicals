## 🎯 Course Objectives

- Design and develop Android applications using Android Studio.

- Gain hands-on experience in Android application development, testing, deployment, and publishing.

# ▶️ How to Run

1. Clone this repository

```
git clone https://github.com/SirsodeRaj/Android-Practicals.git
```

2. Open Android Studio.

3. Select the required practical project.

4. Sync Gradle.

5. Run on an Emulator or Android Device.
